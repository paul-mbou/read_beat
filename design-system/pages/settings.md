# Settings — ReadBeat

## Job
Confirm where files live, whether sync is waiting, and how the desk looks — then leave.

## Ritual
Scan sync status → tap Sync now if signed in → adjust theme or privacy only if needed.

## Composition
- Title + one-line purpose
- Sync glass panel (online / offline / pending / last sync) + one CTA
- Storage snapshot (size + counts) — no fake cleanup chrome
- Appearance segmented control (existing desk pattern)
- Privacy: recap consent off by default + lock-screen notification allow
- Account: sign in / out / delete

## Avoid
Dashboard metrics, second palettes, “premium” privacy illustrations.
