# Library / Search / Queues — ReadBeat

## Job
Find a title fast, heart what you’ll return to, queue audio for a stretch.

## Ritual
Search or filter → tap a cover to resume → heart or add audio to a queue.  
Switch list ↔ 3-col grid (same shelf covers as Home). Preference is remembered.  
Long-press a title to tidy the shelf → circular marks appear (pressed title already checked) → tap more → delete.

## Notes
- Search is local: title > author > format tokens
- Favorites use the orange accent only when active (signature spark)
- Playlists are audio-only listening queues, not discovery playlists
- Empty search explains “no match”; empty shelf invites import
- Remove is a long-press multi-select, not swipe or a per-row trash icon
- Layout toggle: list (dense rows) or grid (covers); works with search, filters, and select mode
- List and grid both show where you stopped: Beat trail + percent (Not started / 65% / Finished)
