# Auth — ReadBeat

## Job
Optional OAuth sign-in (Google / Apple / Facebook) so progress can sync across devices. Library use never requires an account. No email/password.

## First viewport
- **Brand**: ReadBeat (Fraunces display) as hero signal
- **Headline**: “Sign in to sync” when opened for sync; otherwise “Sign in”
- **Support**: Reading/listening work locally; provider account unlocks cross-device sync
- **Primary actions**: Continue with Google · Apple · Facebook (equal weight)
- **Escape**: Close + “Continue without an account” → home library

## Dual theme
Uses MASTER tokens only (`primary`, `primary-bright`, `primary-muted`, glass fill/border, atmosphere gradient). Brand title uses brand-fill gradient.
